# Security Policy

## Supported Versions

Only the latest release of Fairway receives security updates.

| Version | Supported |
| :--- | :--- |
| Latest release | :white_check_mark: |
| Older releases | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in Fairway, please report it privately:

- **Email**: Send details to [richieobodo1738@gmail.com](mailto:richieobodo1738@gmail.com)
- **GitHub**: Use GitHub Private Vulnerability Reporting under the repository's **Security** tab

**Please do not open public GitHub issues or discussions for security vulnerabilities.**

Provide a clear description of the issue, steps to reproduce, and potential impact. While we do not promise a specific response-time SLA, reports will be investigated and addressed as quickly as possible.
